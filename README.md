# Home Recovery & Sleep Wellness — Affiliate Site Starter

海外(US)向けアフィリエイトブログのスターターキット。ニッチ: Home Recovery & Sleep Wellness(自宅リカバリー・睡眠ウェルネス機器)。

## 中身

- Eleventy(11ty)で構築した静的サイト(無料でGitHub Pagesにホスティング可能)
- 英語記事3本(SEOロングテールキーワード狙い、アフィリエイトリンクプレースホルダー付き)
- Pinterest / SNS運用プラン(`docs/pinterest_sns_plan.md`)
- デプロイ手順・アフィリエイト登録手順(`docs/setup_guide.md`)
- FTC対応のアフィリエイト開示ページ、プライバシーポリシーの雛形

## クイックスタート

```
npm install
npx @11ty/eleventy --serve
```

詳細は `docs/setup_guide.md` を参照。
