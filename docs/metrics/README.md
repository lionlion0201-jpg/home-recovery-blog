# metrics

計測まわりのデータ置き場。設計の背景と読み方は
`アフィリエイト/共通/計測設計.md` を参照。

| ファイル | 内容 | 更新者 |
|---|---|---|
| `posted_assets.json` | 投稿した資産(ツイート・ピン)のIDと記事の紐付け台帳 | `run_promotion.py` / `post_pin_backlog.py` が投稿成功時に追記 |
| `x_metrics.json` | ツイートのインプレッション・エンゲージメントの時系列 | `fetch-metrics.yml` が毎日22:00 JSTに追記 |
| `pin_metrics.json` | ピンの表示・保存・サイトへの遷移数の時系列 | 同上。読み取り専用の `PINTEREST_READ_TOKEN` を使う(投稿用トークンとは別) |

**この台帳はIDと紐付けだけを持ち、実測値は持たない。** インプレッションや
クリックなどの測定値は、このIDを使って後からAPIで引き、別ファイルに追記していく。

IDを残していなかったために「投稿はできるが効果は永久に分からない」状態が
2026-09-20まで続いていた。台帳が欠けると後追いが不可能になるので、
投稿処理を変更するときはここへの記録が外れていないか必ず確認すること。
