# 5大ASP登録ガイド(Home Recovery & Sleep Wellnessニッチ向け)

海外(主にUS)アフィリエイトの主要ASPを5つとも押さえるための実務ガイド。難易度は易しい順に並べている。

## 難易度の目安

| ASP | 難易度 | 審査の傾向 |
|---|---|---|
| Amazon Associates (US) | 易 | サイトURLと若干のコンテンツがあれば申請可。ただし180日以内に一定数の適格販売がないとアカウント停止になり得る |
| Impact | 易〜中 | 大手ネットワークでプログラム数が多く、サインアップ自体は軽い。個別プログラムごとに承認が必要 |
| Awin | 中 | ウェブサイトまたはSNSで「オリジナルコンテンツ」と「アクティブな運用実績」が求められる。米国展開を積極拡大中 |
| ShareASale | 中 | 有効なウェブサイト+審査あり。承認まで最大20営業日かかることもある |
| CJ Affiliate (Commission Junction) | 難 | エンタープライズ寄りで審査基準が厳しめ。実績のあるサイトでないと個別プログラム承認が通りにくい |

**申請の順番は上から**が基本方針。Amazonでまず実績(記事本数・多少のトラフィック)を作り、Impact→Awin→ShareASale→CJの順で申請するとスムーズ。

---

## 1. Amazon Associates (US)

- 申請先: https://affiliate-program.amazon.com (日本のAmazonアソシエイトとは別プログラムなので注意)
- 必要なもの: 公開済みのサイトURL、Associate IDの希望名
- 審査ポイント: サイトに実際のコンテンツがあること。空のテンプレートサイトは却下されやすい → 今回作った3記事+今後追加する記事で対応
- 注意点: 承認後180日以内に一定件数の適格販売がないとアカウントが閉鎖されることがある(規約は変わることがあるので登録時に必ず最新条件を確認)
- このニッチでの使い道: 個別製品(レッドライトパネル、サウナブランケット、加重ブランケット等)へのリンクに幅広く使える、最初の主力ASP

## 2. Impact

- 申請先: https://impact.com (Partnershipsとして参加登録)
- 必要なもの: サイトURL、簡単なプロフィール
- 審査ポイント: ネットワーク自体への登録は軽いが、個別ブランドのプログラムごとに承認申請が必要
- このニッチで探すべきプログラム例: AG1のようなウェルネス系サブスクリプション商品(リカーリング狙いに好相性)、その他のサプリ・リカバリー系D2Cブランド
- 探し方: Impactのマーケットプレイス内で "wellness" "recovery" "sleep" などで検索し、個別に申請

## 3. Awin

- 申請先: https://www.awin.com
- 必要なもの: 独自コンテンツのあるサイトまたはSNSアカウント、アクティブな運用実績
- 審査ポイント: 「オリジナルコンテンツ」があるかを見られるため、記事が数本ある状態で申請するのが安全
- このニッチでのプログラム例: Emma Sleep(マットレス、コミッション率は公開情報ベースで6%台)などのSleep系ブランドが確認されている。MyProtein等のウェルネス系ブランドも参加
- 補足: ShareASaleの親会社であり、米国展開を積極的に進めている

## 4. ShareASale

- 申請先: https://www.shareasale.com
- 必要なもの: 有効なサイトURL、申請フォーム、規約への同意
- 審査ポイント: 承認まで最大20営業日かかる場合がある。気長に待つ前提でスケジュールを組む
- このニッチでの使い道: 25,000以上のマーチャントを抱える大規模ネットワークなので、home/wellness系の個別ブランドを幅広く探せる

## 5. CJ Affiliate (Commission Junction)

- 申請先: https://www.cj.com
- 必要なもの: 実績のあるサイト(トラフィック・記事数がある状態が望ましい)
- 審査ポイント: エンタープライズ寄りで最も厳しい。個別プログラムの承認も通りにくい傾向
- このニッチでのプログラム例: Mattress Firmのような大手寝具チェーンが確認されている(コミッション率は公開情報ベースで3%台とAmazon並みかそれ以下のことも多いが、ブランド力・単価の高さで補える)
- 申請タイミング: 他の4つで実績を積んでから、最後に挑戦するのが現実的

---

## 運用上の注意

- コミッション率・規約は各社が随時変更するため、実際に申請する直前に必ず公式サイトで最新情報を確認すること(本ガイドの数値は申請可否の目安であり、確定条件ではない)
- 同じ商品カテゴリでも、Amazon Associatesと個別ブランドプログラムでコミッション率が大きく異なることがある(個別プログラムの方が高いことが多い)。記事内のリンクは「まずAmazon、承認が取れ次第、単価の良い個別プログラムに差し替え」という運用にすると機会損失が少ない
- マーケター役(`agents/marketer.md`)は、新しい記事を提案する際にこの5ASPのうちどれを狙うかを明記すること
